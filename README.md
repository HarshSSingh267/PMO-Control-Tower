# PMO Control Tower – Consulting Project Portfolio Management System

A simulated Project Management Office (PMO) environment designed to monitor and manage a portfolio of concurrent BFSI and technology implementation projects through centralized project controls, delivery tracking, resource management, financial monitoring, risk management and executive reporting.

**Project Type:** Simulated PMO / Consulting Project  
**Portfolio Size:** 5 Concurrent Projects  
**Technology Stack:** Microsoft Excel, Microsoft Project, Jira, Power BI, PowerPoint, Microsoft Visio  
**Project Status:** In Progress

---

## 1. Project Overview

The PMO Control Tower demonstrates how a centralized Project Management Office can establish governance, operational control and management visibility across multiple concurrent projects.

The system integrates project schedules, milestones, tasks, budgets, resources, risks and issues to help project managers and senior management monitor delivery performance, identify deviations and support informed decision-making.

The project uses a fictional consulting portfolio and simulated datasets. It is independently developed for demonstration and learning purposes and does not represent an actual client implementation.

## 2. Project Objectives

- Establish centralized visibility across a five-project portfolio.
- Monitor project health through Red-Amber-Green (RAG) indicators.
- Track planned versus actual progress and milestone completion.
- Monitor project budgets, expenditure and financial variances.
- Identify and escalate project risks, issues and overdue activities.
- Analyse resource allocation and capacity utilisation.
- Develop interactive management dashboards and structured executive reporting.
- Demonstrate an integrated PMO operating and governance framework.

## 6. Excel-Based PMO Control System

The central Excel workbook provides operational tracking through nine integrated modules:

1. Project Portfolio Tracker
2. Project Task Tracker
3. Milestone Tracker
4. Risk Register
5. Issue Register
6. Resource Allocation Tracker
7. Budget Tracker
8. Weekly Status Report
9. PMO Analytics Dashboard

**Key functionalities:**

- Automated project RAG status indicators.
- Planned versus actual progress monitoring.
- Task overdue and escalation alerts.
- Milestone tracking and delivery monitoring.
- Risk scoring and escalation flags.
- Issue ageing and resolution tracking.
- Resource capacity and utilisation calculations.
- Budget utilisation and expenditure variance analysis.
- PivotTables and charts for portfolio-level analysis.

## 7. Power BI – Interactive PMO Dashboards

Power BI is used to transform the operational data from the PMO workbook into interactive management dashboards.

The solution includes a centralized data model, DAX-based measures, KPI cards, charts, slicers and detailed reporting tables.

**Five dashboard pages have been developed:**

### 7.1 Portfolio Overview
Provides an executive-level summary of the five-project portfolio.

- Total projects and RAG distribution.
- Projects on track, at risk and delayed.
- Overall portfolio progress.
- Approved budget, actual expenditure and remaining budget.
- Project-wise progress comparison.
- Financial overview and portfolio health distribution.

### 7.2 Project Delivery & Schedule Performance
Monitors project execution and schedule performance.

- Total, completed and in-progress tasks.
- Overdue tasks and upcoming deadlines.
- Task completion rate.
- Task status distribution.
- Planned versus actual project progress.
- Milestone tracking and task-level details.
- Overdue task analysis by project.

### 7.3 Financial Performance
Provides visibility into project budgets and expenditure.

- Approved budget and planned expenditure.
- Actual expenditure and remaining budget.
- Budget utilisation.
- Spend versus plan variance.
- Project-wise budget utilisation.
- Approved versus actual expenditure analysis.
- Project financial detail table.

### 7.4 Risk & Issue Management
Supports project governance through risk and issue monitoring.

- Total, critical and escalated risks.
- Total, open and overdue issues.
- Risk priority distribution by project.
- Issue severity versus resolution status.
- Risk and issue exposure comparison.
- Escalation monitoring and governance register.

### 7.5 Resource Management & Capacity Planning
Provides visibility into resource allocation and workforce capacity.

- Total resources and weekly capacity.
- Allocated hours and overall utilisation.
- Overallocated and near-capacity resources.
- Resource-wise utilisation analysis.
- Available versus allocated hours by role.
- Resource capacity distribution.
- Resource allocation and recommended action register.

**Power BI capabilities demonstrated:**

- Data transformation using Power Query.
- Data modelling and table relationships.
- DAX measures for portfolio, financial, delivery, risk, issue and resource KPIs.
- Interactive slicers and cross-filtering.
- KPI cards, bar charts, column charts, donut charts, matrices and reporting tables.

# PMO Control Tower – Consulting Project Portfolio Management System

A simulated Project Management Office (PMO) environment designed to monitor and manage a portfolio of concurrent BFSI and technology implementation projects through centralized project controls, delivery tracking, resource management, financial monitoring, risk management and executive reporting.

**Project Type:** Simulated PMO / Consulting Project  
**Portfolio Size:** 5 Projects  
**Tools:** Microsoft Excel, Microsoft Project, Jira, Power BI, PowerPoint, Microsoft Visio  
**Status:** In Progress

---

## 1. Project Overview

The PMO Control Tower demonstrates how a centralized PMO can establish governance and visibility across multiple concurrent projects.

The system brings together project schedules, milestones, tasks, budgets, resources, risks and issues to help project managers and senior management monitor delivery performance and identify potential deviations.

The project uses a fictional consulting portfolio and simulated datasets. It is intended for demonstration and learning purposes and does not represent an actual client implementation.

## 2. Objectives

- Establish centralized visibility across a five-project portfolio.
- Monitor project health through Red-Amber-Green (RAG) indicators.
- Track planned versus actual progress and milestone completion.
- Monitor project budgets, expenditure and financial variances.
- Identify and escalate project risks, issues and overdue activities.
- Analyse resource allocation and capacity utilisation.
- Develop management dashboards and structured executive reporting.

## 6. Excel-Based PMO Control System

The central Excel workbook provides operational tracking through the following modules:

1. Project Portfolio Tracker
2. Project Task Tracker
3. Milestone Tracker
4. Risk Register
5. Issue Register
6. Resource Allocation Tracker
7. Budget Tracker
8. Weekly Status Report
9. PMO Analytics Dashboard

The workbook includes automated RAG indicators, overdue alerts, risk escalation flags, resource utilisation calculations, budget variance analysis and consolidated portfolio KPIs.
